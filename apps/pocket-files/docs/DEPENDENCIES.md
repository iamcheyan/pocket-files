# Dependencies

Backend: Go standard library and `modernc.org/sqlite` (pure Go SQLite, no CGO). Frontend: React, React DOM, Vite, TypeScript, Lucide icons. Development uses Bun and Go.

No Electron, native filesystem browser bridge, udisks client, downloadsd client, or PJOS app registry client is included yet. Dependency lockfiles are generated by the package manager during setup/build and must be committed for reproducible publication.
