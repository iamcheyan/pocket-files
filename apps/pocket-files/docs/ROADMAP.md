# Roadmap

Current: runnable React/Vite shell, English/Chinese/Japanese labels for core views, four generated mock volumes, browse/search by name/extension, mock folder creation, SQLite startup schema, and a root sandbox in the provider.

Next: split `filesd` and `storaged`; Linux read-only discovery fixtures; full parameterized API and SQLite migrations; durable favorites, recents, tags, settings, and transfer journal; Trash/undo; safe operation APIs and full search/filter/sort; PJ app/download clients; previews; storage analytics; keyboard/D-pad/gamepad navigation; device profiles and DPI; accessibility and full translation parity; API and UI integration coverage; real-browser screenshot matrix.

Real device mutation remains disabled until discovery, explicit confirmation, recoverability, sandboxing, and tests are delivered together.
